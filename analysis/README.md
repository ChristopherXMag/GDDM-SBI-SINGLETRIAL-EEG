# Analysis helpers

| File | Purpose |
| --- | --- |
| [`run_parameter_recovery_analysis.py`](run_parameter_recovery_analysis.py) | Posterior recovery metrics, empirical interval coverage, and recovery plots |
| [`posterior_predictive_check.py`](posterior_predictive_check.py) | Generate simulations from posterior parameter samples and compare behavioral/EEG summaries |
| [`analyze_multiple_subjects2.py`](analyze_multiple_subjects2.py) | Read subject CSV files, estimate parameters, and save subject comparisons and descriptive reports |
| [`trial_dynamics_visualization.py`](trial_dynamics_visualization.py) | Illustrative dynamics and parameter-dependency visualizations |

These files expose functions for use from analysis sessions and notebooks. Their usage examples are comments, not complete command-line interfaces. See [reproduction notes](../docs/reproduction.md) for import setup and historical analysis assumptions.
